# Millainen system prompt toimii agentille yleensä parhaiten?

## Ratkaisu

Hyvä system prompt on 'oikealla korkeudella': riittävän tarkka ohjaamaan ja riittävän yleinen, jotta malli soveltaa sitä järkevästi. Kerro *miksi* sääntö on olemassa, jolloin malli osaa soveltaa sitä myös rajatapauksissa. Jäsennä osiin (tausta, ohjeet, työkaluohjeet, tulosmuoto).

## Käytännössä

Aloita minimaalisella promptilla parhaalla mallilla ja lisää ohjeita vain havaittuja virheitä korjaamaan.
