# Mikä on AGENTS.md- tai CLAUDE.md-tiedoston tarkoitus repossa?

## Ratkaisu

Agentti aloittaa jokaisen session tyhjästä. Muistitiedosto repon juuressa (AGENTS.md on työkaluriippumaton käytäntö, CLAUDE.md Claude Coden oma) kertoo miten projekti buildataan ja testataan, mitkä ovat tyylisäännöt ja mitä ei saa tehdä.

## Käytännössä

Pidä tiedosto lyhyenä ja konkreettisena. Jokainen rivi vie kontekstia joka sessiossa, joten poista vanhentuneet ohjeet.
