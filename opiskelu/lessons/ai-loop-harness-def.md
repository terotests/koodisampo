# Mitä 'harness' tarkoittaa AI-agentin yhteydessä?

## Ratkaisu

**Harness** (valjaat) on ohjelma, joka kääntää kielimallin agentiksi. Malli päättää *mitä* tehdään; harness ajaa työkalut, kokoaa kontekstin, pitää kirjaa historiasta, valvoo oikeuksia ja lopettaa silmukan. Esimerkkejä: Claude Code, Codex CLI, Cursorin agentti, oma Agent SDK -sovellus.

## Käytännössä

Kun agentti toimii huonosti, vika on yhtä usein harnessissa (huonot työkalukuvaukset, paisunut konteksti) kuin mallissa. Harnessin laatu ratkaisee paljon.
