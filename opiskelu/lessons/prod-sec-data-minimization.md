# Analytiikka lähettää email, fullName, page, IP ja userAgent. Mitä security/privacy-reviewissa kysyt?

## Tilanne

Analytiikka lähettää email, fullName, page, IP, userAgent.

## Ratkaisu

Security/privacy-review:

- Tarvitaanko henkilötietoa tähän tapahtumaan?
- Voiko käyttää pseudonyymiä userId:tä?
- Kuinka kauan data säilytetään?
- Kuka pääsee siihen?
- Päätyykö data kolmannelle osapuolelle?
- Miten käyttäjän poistopyyntö toteutuu?
